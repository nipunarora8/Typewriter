A tiny desktop todo widget

Your todos, on a typewriter.

Click the keyboard and a paper sheet slides up with your tasks. They live in plain Markdown files you own, so they work with Obsidian too. No account. No cloud.

    What it does

    Small on purpose.

    One widget on your desktop, one folder of notes. That is the whole idea.

    Plain Markdown

    # 2026-10-05
- [ ] Water the plants
- [ ] Call mum
- [ ] Book dentist

    Every task is a checkbox line in a .md file. Open the folder in Obsidian, grep it, sync it with whatever you like.

    A note per day

    • 2026-10-03.md
    • 2026-10-04.md
    • 2026-10-05.md

    Each list is a folder of YYYY-MM-DD.md notes. The red + starts today's note. Step back through older days with the arrows.

    Bring over leftovers

    2 unfinished from 2026-10-04 Bring them over

    Did not finish yesterday? One press carries the unfinished tasks into today's note. Or say "Not now" and start clean.

    Lists, one click away

    PERSONAL

    Work, personal, reading: each list is its own folder. The < NAME > arrows above the keys switch between them.

    Light or dark

    Warm Ivory paper or a dark Midnight desk. Try them: these buttons, or the sun in the header, restyle this whole page.

    Private and offline

    0 accounts 0 servers 0 trackers

    Your tasks never leave your disk. Typewriter makes no network call unless you press "Check for updates".

    Download

    Put one on your desk.

    Free and open source. One command installs it on macOS (Apple Silicon) and Linux (x86_64). Paste it into Terminal. 

    curl -fsSL https://raw.githubusercontent.com/nipunarora8/Typewriter/main/install.sh | sh

    Prefer a file? Download it yourself from the latest release:

    macOS Apple Silicon

    Download the .dmg
    1. Open the .dmg and drag Typewriter to Applications.
    2. macOS may say the app is “damaged”. It is not: the app is just unsigned. Run this once in Terminal, then open it normally: 
    xattr -dr com.apple.quarantine /Applications/Typewriter.app

    Linux x86_64

    Download the .AppImage

    Then run it. No root needed:

    chmod +x Typewriter*.AppImage
./Typewriter*.AppImage

    Unsigned builds. Typewriter is not code-signed or notarized. The install command avoids the macOS “damaged” warning. You can read the installer and every line of the source, and build it yourself.
